# أذكاري | أذكار الصباح والمساء

موقع ثابت (HTML واحد) لأذكار الصباح والمساء الصحيحة بمصادرها، مع مسبحة لكل ذكر، وتحكم بحجم الخط، ووضع ليلي/نهاري.

## التشغيل محلياً
افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages
الموقع ملف واحد في جذر المستودع (`index.html`)، جاهز للنشر عبر GitHub Pages من فرع `main` / مجلد `/ (root)`.

الرابط بعد النشر سيكون:
`https://<username>.github.io/<repo>/`
